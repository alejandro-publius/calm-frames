# Calm Frames

A verified safety layer for Fire TV (Vega OS) for kids with photosensitive epilepsy. Every frame of a title is checked before it can play in kid mode. Flagged flashing segments are hidden before they start, while sound and captions keep going.

**Status:** early development for Build, Ship, Shape: Amazon Developer Hackathon (Fire TV track). Nothing has been measured yet, so this README reports no results.

Calm Frames reduces exposure to flashing above published limits in the videos it plays. It is not a medical device.
