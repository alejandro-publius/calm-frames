# Submission status

This is a repository status note, not a copy of submitted Devpost answers and not
proof of submission. The previous placeholder-filled draft is superseded; its
history remains in Git. Do not paste old roadmap promises, test counts or safety
claims into a submission as current facts.

Calm Frames is a native Vega OS Fire TV prototype for people with photosensitive
epilepsy and their caregivers. It explores prepared media, offline analysis,
signed artifact identity and guarded playback. It is not a medical device, has
not been clinically validated and cannot guarantee seizure prevention. It does
not intercept other apps or arbitrary streams system-wide.

The [README](../README.md#start-here) identifies the exact public source snapshot,
its build instructions and the earlier demo. The latest local native repairs are
not in that snapshot. No public downloadable accepted build is provided here.
Debug observations do not establish final Release acceptance; pause announcement
reliability, dependency findings and other native acceptance gaps remain open.
New media preparation and editorial assets are not a finished native demo.

The actual live form, submitted answers, eligibility and organizer decisions must
be checked on Devpost separately. This documentation change does not edit or
attest to that form, publish a release or change the demo video.
