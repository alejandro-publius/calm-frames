## The Oct 13 draft ZIP, kept as history

[The October 13 draft](calm-frames-submission-draft-2026-10-13.zip) was
assembled at `7444d21` and is **not current**: its copy, browser previews and
recording plan predate the Oct 14 design integration and the candidate above.
It is kept for the record. Do not use its previews in the gallery without
relabelling them as the Oct 13 layout. On GitHub, use **Download raw file** on
the ZIP page.

It collected the shorter project story, detailed form guidance, browser
previews, approved brand assets, the Mac recording plan, an unfilled capture
template and a file manifest. It contained no native package and no finished
demo. The ZIP passed its CRC check, every payload hash matched the manifest,
and its extracted files passed the secret scan. Its SHA-256 is:

```
2dfe87af26085358a15b154cd8aee8bdb5fdbebc6046fddb3afb9c5ade1cac21
```

It was committed here because the cloud environment blocked
`uploads.github.com`; the existing draft release assets were preserved. The
upload attempt and source identity are recorded in
[github_handoff_2026-10-13.json](../../results/github_handoff_2026-10-13.json).
