publicKeyFor. It returns a fresh read-only presentation object, including source,
selected rendition, map, report and checked-input hashes. It does not authorize
playback. Existing guard verification and acceptsRoute remain required.

after normal title verification and labels merged/padded playback intervals
separately. Source and output checks use the same analyzer; this is stated.
