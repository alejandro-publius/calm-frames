# Documentation guide

Start with the [project overview and public provenance](../README.md). The
[submission status note](SUBMISSION.md) is repository documentation, not a
submitted answer. The README links to the newer public October source snapshot;
relative source links on this default-branch lineage still refer to September.

## Historical engineering evidence

- [Evaluation plan](EVAL_PLAN.md) and [committed results](../results/) preserve
  methods and observations with their original scope.
- [Gate log](GATES.md), [status history](STATUS.md) and [decisions](DECISIONS.md)
  retain dated work, failures and withdrawn measurements.
- [Sidecar format](SIDECAR_SPEC.md), [analyzer](../flashmap/README.md) and
  [integration hook](../hook/README.md) document developer tools on this tree.
- [Release procedures](RELEASE.md) describe preparing artifacts, not an available
  accepted download. Follow the pinned October instructions from the README when
  inspecting that source.
- [Safety record](SAFETY.md) preserves handling precautions. Historical wording
  must not be read as a medical or individual viewing guarantee.

Other planning, feedback, outreach and video-script documents on this tree are
historical drafts unless explicitly dated otherwise. They do not establish
current implementation, organizer approval, actual submission, deployment status
or final release acceptance. The measurements and their limitations remain
available; superseded product descriptions do not override the README.
