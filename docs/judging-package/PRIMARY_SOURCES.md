## Evidence versus authority

Primary sources establish the official criteria, the existence of published flash guidance, or the problem context. Repository files establish what this prototype implements and what was observed. Neither category substitutes for the other. Test counts are not population evidence; an advocacy page is not proof that a particular video is safe.

Before public use, re-open P1 to confirm the current judging text and P2/P3 to confirm any retained quotations. Keep a dated record of the section actually read. If wording changes, update the brief and ledger rather than silently preserving the earlier claim. This is a factual gap, not a reason to invent a replacement source.
